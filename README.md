# AUREX — UAE LED Display Solutions

AUREX General Trading FZE LLC website focused on LED screen supply, installation, components, project support and annual maintenance enquiries across the UAE.

## Pages
- `index.html` — LED-focused homepage
- `services.html` — supply, installation, subcontracting, maintenance and AMC
- `products.html` — LED modules, cabinets, controllers, sending/receiving cards and accessories
- `projects.html` — illustrative LED application gallery
- `about.html` — company overview
- `contact.html` — contact details and email-based enquiry form

## Technology
Static HTML, CSS and JavaScript. No Supabase, database, authentication or server-side form storage is used. The contact form prepares an email using the visitor's email application.

## Publish
GitHub Pages can serve the root of the `main` branch. The custom domain is configured in `CNAME`. Review this redesign branch before merging it into `main`.
